# STUDIO homepage

This is a self-contained, responsive homepage for the Caltech Studio research group.

## Publish on GitHub Pages

Copy `index.html` into the root of the `angkur2709/studio` repository, commit the change, and wait about one minute for GitHub Pages to rebuild.

The homepage is CMS-enabled with Pages CMS. Keep these three files together in the repository root:

- `index.html` — visual design
- `content.json` — editable website content
- `.pages.yml` — CMS field definitions

To edit the site, visit https://app.pagescms.org, sign in with GitHub, install the Pages CMS GitHub App for `angkur2709/studio`, and select **Homepage**. Saving a field commits the updated content to GitHub and GitHub Pages republishes the site.
